我的工作 Agent 查资料、做分析、写材料；私人 Agent 更多处理行情、新闻和日常简报。这两类信息的频率和用途不同，我把它们的记忆分开。

否则一天的碎片资讯可能挤进长任务的上下文，之前的判断反而不好找。

## 资源可以共享，写入要另说

两个 Agent 可以使用共享知识库和工具。但对关键记录，私人 Agent 只读；需要修改时经过规定的工作流程。

分开记忆只解决上下文问题。写权限还需要在工具层限制，不能指望一句角色说明就完成控制。

## 边界怎么决定

我会看写错之后影响谁、能否恢复，以及修改前需要哪些核查。私人 Agent 自己生成的摘要，与会进入业务结论的记录，可以采用不同规则。

每次添加工具或新任务，都要再看一遍这些边界。Agent 的数量不重要，职责和权限能否对上实际工作更值得检查。
