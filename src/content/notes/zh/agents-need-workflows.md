过去几年，处理行为数据的默认想象是：只要模型足够强，把视频、眼动、生理信号和事件日志一起交给它，答案自然会出现。

这低估了实际工作的复杂度。

在一个真实项目里，分析者首先要确认文件属于哪个参与者、采集时钟是否一致、缺失片段发生在哪里、传感器质量是否足以支持结论。接着才是切分任务、提取特征、比较条件、生成图表。最后还要把每一个结论追溯到原始记录，并说明哪些地方只是推断。

模型可以帮助其中某一步，但它不会自动把这些步骤变成一条可靠的工作流。

## 从「回答问题」转向「承担流程」

我更关心 Agent 的三个能力。

第一是**维持上下文**。它需要知道当前处理的是哪位参与者、哪个实验阶段、哪一个数据版本，以及上一步产生了什么中间结果。没有这个上下文，再聪明的回答也可能属于错误的数据片段。

第二是**调用确定性工具**。时间戳对齐、信号滤波、缺失值检查和统计检验，应尽量交给可重复执行的程序，而不是让语言模型凭文本猜测。Agent 的价值，是判断何时调用哪一个工具，并把结果带入下一步。

第三是**留下证据链**。一次分析应该能回答：输入是什么，执行过哪些操作，哪些阈值由人设定，哪些异常被排除，结论对应哪些数据。不能被复核的自动化，只是把不确定性藏得更深。

## 人仍然负责边界

行为数据常常涉及个人信息、健康状态或敏感场景。Agent 不应该自行扩大数据使用范围，也不应该把相关性写成因果关系。研究者仍需要定义问题、确认授权、审批关键排除规则，并对最终解释负责。

所以我把理想系统理解为一个分层结构：

1. 确定性工具负责计算；
2. Agent 负责组织任务、检查状态和连接工具；
3. 人负责意图、边界和判断；
4. 日志负责让全过程可以追溯。

这也是我在 PsyPhiClaw 中验证的方向。它还不是一个被充分验证的产品，而是一个开放实验：把多模态行为研究里反复出现的步骤做成模块，再观察哪些部分适合自动化，哪些部分必须保留人工检查点。

## 更大的模型不是终点

模型能力会继续上升，但专业工作的可信度不会自动随参数增长。真正能进入研究与工程现场的系统，需要同时处理文件、工具、权限、异常和复核。

对行为科学而言，Agent 的意义不是替研究者得出一个更快的答案，而是让复杂分析第一次有机会成为可检查、可复用、可持续改进的流程。
