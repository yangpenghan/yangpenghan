# 试点方案与任务卡

## 设计

目标是比较任务方法变化前后的人工负担与验收结果。先完成 W00 热身以熟悉记录流程，热身不进入比较，也不补录计时。随后执行 3 个预登记配对。每对包含难度相近、主题不同的两项任务：一项纯人工，一项 Agent 辅助。开始前把文末模板复制到私有记录，锁定配对、任务、条件顺序、截止日期、模型、工具、权限和 skill 版本。

建议交替顺序为：P01 人工→Agent，P02 Agent→人工，P03 人工→Agent。每项只用于一个条件，防止读过同题答案带来学习效应。若重试，沿用同一 `pair_id`、`condition` 和 `task_id`，换新的 `trial_id`；验收通过后停止该条件。环境或标准有偏离时照常保留记录并在 `notes` 说明。

两种条件使用完全相同的交付与验收标准。记录质量验收本身所需的人时；五个人工阶段互斥。失败仍计入尝试次数和已知成本。首轮样本很小，主题差异、顺序效应和熟练度都可能影响结果，只用于决定是否继续、调整或停止工作流，不做因果或显著性宣传。首轮同时引入的流程变化不能归因于某项 skill。要评估单个 skill，后续须固定模型、工具、权限、提示词和任务难度，只改变该 skill。

## 固定验收表

- **事实**：5 条主张均可由所引来源核查；日期、数字、主体和限定语无明显错误。
- **引用**：至少 5 个可访问来源、至少 3 个一手来源；5 条主张逐条引用到具体来源；链接可打开。
- **覆盖**：回答任务卡问题，并包含矛盾证据和限制；不回避会削弱建议的材料。
- **格式**：中文正文 800–1200 汉字；写明问题与检索截止日期；事实、推论、建议明确分开。

四项都通过才接受。`quality_notes` 必须逐项记录；不通过或未知不能隐藏。

## 热身卡（不纳入比较）

**W00｜如何判断 Agent 与 skills 是否减少研究简报的人工负担？** 使用协调者已完成的热身稿熟悉验收表和计时字段，不把热身的人时或结果写入正式比较。

> 截至【YYYY-MM-DD】，用公开可访问来源研究“如何判断 Agent 与 skills 是否减少研究简报的人工负担？”。交付 800–1200 汉字中文简报，至少 5 个来源且至少 3 个一手来源。列出 5 条可核查主张并逐条引用，分开事实、推论和建议，呈现矛盾证据与限制。不得把小样本描述写成因果或显著性结论。
