# 技术与思考：长文扩展

日期：2026-09-06。范围：现有个人网站的内容扩展与阅读体验。

## 编辑判断

现有 12 篇中文与 12 篇英文文章已经交代工作方式，但除核心主张外，多数为两分钟的简短笔记。需要补足定义、推理、替代解释、方法选择、反例与下一步检验，使案例之外也能看见作者持续研究的问题。

本次材料是用户提供的《总结思考方式》共享对话，其中主体为 GPT 对历史讨论的四组十二条归纳。已读取共享页实际正文；并未取得归纳所引用的所有历史消息。它支持选题与思考方向，不独立证明履历、项目成效、客户条件或已经完成的实证研究。原始网页与解析数据保存在工作区外，不进入公开仓库。

主线：人类行为如何被表达，表达如何接受现实检验，方法如何进入持续工作，判断又对谁、在什么条件下成立。第一人称文章属于本次授权下的编辑展开。假设场景明确标示，不增添个人轶事，不将模型提案写成已验证产品。

## 网站接入

- 保留四个分类及其锚点，扩充分类说明，新增四条按论证递进组织的阅读路径。
- 长文自动生成二级标题目录。关联阅读优先沿专题继续，并可跨到相关问题。
- 首页精选加入新长文；核心主张继续保留入口，并补充通往新论证的链接。
- 采用既有字体、颜色与原生静态 HTML，不新增客户端依赖。

## 依据与验收

技术定义与研究结论优先核对作者论文、大学教材和原始出版来源。外部文献仅支撑其实际覆盖的论断；作者提出的方法与假设场景分别说明。

执行 Biome、Astro check、Vitest、生产构建与浏览器审计。检查双语 slug 配对、阅读路径目标、相关文章、目录锚点、基路径、全部新页面移动端溢出与无 JavaScript 阅读。已有未提交修改在工作区外备份，本轮只在当前网站基础上增量更新。
