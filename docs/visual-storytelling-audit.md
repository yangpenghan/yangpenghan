# 网站可视化评估与实施 · 2026-09-06

> 本文记录第一轮结构评估。第一版图形被反馈为过于简陋；目前已完成表现层重做，最新设计依据与验证见 [视觉精修](visual-refinement.md)。

## 判断标准

先判断读者需要理解什么，再决定形式：结构用关系图，时间与迭代用流程，推理选择用交互对照，真实材料用带来源的预览。观点正文与合作说明继续保留文字。图形要减少解释负担，不能只是给原来的文字换个框。

## 系统评估

| 页面 / 区域 | 当前阻力 | 本轮处理 | 优先级 |
| --- | --- | --- | --- |
| 首页首屏 | 主张有力，但右侧重复大标识，没展示“重构” | 用目标、限制、工具、行动与反馈的关系图解释主张；保留人物与岗位 | P0 |
| 首页、案例目录的代表案例 | 三个案例都是同一种文字索引，缺少视觉记忆点 | 三种不同图形：记录到问题的证据结构、开发中的迭代回路、机器人与后台人员的交互模型 | P0 |
| 元思维 / 方法页 | 四段方法和表格要求读者自行想象转换过程 | 可切换的三组问题推演，原提问、关键重构与具体行动并列；流程图随选择变化 | P0 |
| 工具箱 | 名字与说明很多，缺少工具在流程中做什么的直观表达 | 复用素材库的观察、模拟、知识库、Agent 图标，配合输入→工具→用途的图解 | P1 |
| 医疗案例与关于页 | 公开演讲只有 PDF 下载入口，真实方法材料埋得太深 | 引入现有公开演讲第 20 页过程图的图片预览，附年份、页码、文字解读和原文入口 | P1 |
| 技术与思考 | 分类仍是一组文本链接，主张与议题的关系不明显 | 可点击的议题关系图，连接核心主张与四个议题 | P1 |
| 核心主张长文 | 连续长文缺少可停留的结构概览 | 增加问题重构与检验的图解；完整论证继续保留 | P1 |
| 其他案例、文章、经历与联系 | 具体解释仍有必要，强行加图会重复 | 保留简洁文字；关于页以真实演讲材料增加变化，避免每节同模板 | P2 |

## 素材盘点与选择

- 品牌 V2 素材库固定版本 `acea2b2d43b6bf9fe2f1ab745a076b6b3bd11df7`：已有字体、标识；本轮扩展使用 observation-glyphs 中的观察、测量、知识与工作流图标。
- 现有公开 PDF `public/talks/2020-medical-device-hf-safety.pdf`：38 页。选择第 20 页“洞察—迭代—确认”作为演讲材料预览，保留原样；不把历史演讲写成当前法规指导。
- 私有素材清单与 2019 年公开演讲用于核对可视化背景。客户界面、参与者照片、原始结果、未经确认的项目运行截图不用于装饰。
- 本轮绘制的关系图、流程图标明为方法示意。金融案例只使用已公开核对的 254GB / 86 个问题，图中的连线、图形数量不代表样本分布或效果提升。

## 实施与验证计划

1. 创建共用关系图、案例图与演讲预览；复用图标资产并记录来源。
2. 将图形接入首页、代表案例、工具箱、方法、思考栏目与核心文章；控制文字重复。
3. 对可切换推演实现键盘操作、状态语义及无 JavaScript 降级。
4. 检查双语、浅深色、390px/320px、减少动效、字体子集和素材加载；运行构建、内容测试、全站浏览器审计与新增交互检查。

## 实施结果与验收

- 新增 `ProblemMap`、`CaseDiagram`、`ReframeExplorer`、`ToolInstrument`、`TopicMap`、`PublicSlide` 六个共用组件，接入中英文首页、方法、代表案例目录与详情、思考栏目、主张文章和关于页。
- 首页大标识替换为带反馈回路的问题关系图，保留人物、职位、首屏宣称与解释。代表案例使用左右交替的图文布局，其他案例仍保留便于扫读的索引。
- 方法对照表替换为三场景推演。Tab / 方向键 / Home / End 可操作，选中状态和面板语义同步；无 JavaScript 时隐藏切换控件并完整显示三组内容。
- 演讲图片是现有公开 PDF 第 20 页的完整渲染，1440×810，约 161 KiB。页面附文字解读与 PDF 页码入口；原始样式保留，不重新包装为当前项目结果。
- 未引入图表运行库或客户端框架。图形由可选择文本的 SVG / HTML 构成，复用现有主题、字体和图标资产；新增字体字符已纳入本地子集。

最终验证：

- `npm run verify`：Biome 通过；Astro 50 个文件，0 errors / warnings / hints；Vitest 4 项通过；构建 56 页。
- `npm run audit:browser`：54 个 HTML 页面和 1 个 PDF 正常，0 浏览器错误，20 组 axe 检查通过；54 页在 320px 无横向溢出。
- `npm run audit:visuals`：中英文 × 1440px / 390px 共 4 组场景通过，逐一检查三个面板、键盘切换、图形 ID 唯一性、四个议题锚点、演讲图片加载和原文链接；12 次面板 axe 检查通过。无 JavaScript 时三组内容全部可见。
- 视觉复核：中英文首屏、手机推演、三案例布局、工具箱、议题图、历史演讲预览；截图和日志位于本地 `artifacts/visual-refresh/visual-*`。
- 交互测试修正了懒加载图片尚未开始解码时就读取图片的时序：滚动进入视口后等待图片完成加载再验证，而非放松资源检查。
- `git diff --check` 通过。未提交或部署。
