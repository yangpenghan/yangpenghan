# 核心叙事重构 · 2026-09-05

## 来源与定位

用户本轮明确提出：所有问题都是技术性问题；技术指系统性拆解、重构问题、使用可及工具寻找办法。这是本轮文章的原始主张，后续论证是获授权的编辑拓展，不冒充历史聊天摘录。此前未取得的 ChatGPT 历史仍不作为来源。

## 实施顺序

1. 首页首屏直接呈现宣称，紧接着解释“技术”的含义，连接主张全文与实际案例。
2. 新增中英文主张文章，说明问题定义、约束、关系、实验、价值取舍与判断边界。技术与思考栏目优先推荐。
3. 方法页明确展示元思维：如何检查题目本身、辨别原因、重组条件、检验自己的判断。保留合作启动与交付说明。
4. 增加可复用工具箱，列实际手段、具体用途与案例依据，避免品牌标签墙与熟练度自评。
5. 为十个中英文案例补充“重构的问题”，统一首页、栏目介绍、关于与分享图叙事。
6. 运行 lint、类型检查、内容测试、构建与浏览器审计；检查中英文、窄屏、暗色与文章链接。

## 编辑约束

- 宣称是工作立场，不伪装成已经证明的普遍定理；不能承诺任何固定条件下任何目标都可实现。
- 价值选择由参与者作出，技术让选择、代价、行动和反馈更清楚，不替人决定什么值得追求。
- 问题重构改变切入点，必须保留原目标与验收标准，不把换了问题当成解决了问题。
- 案例问题表述为作者对实践的归纳，不伪造客户原话、绩效、历史言论或产品成熟度。
- 保留当前视觉品牌、角色归属、商业交付渠道及原型状态。
